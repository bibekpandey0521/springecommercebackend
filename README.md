# 🛒 Spring Boot E-Commerce Backend

This is a backend project for an e-commerce platform built using **Java Spring Boot**. The system supports product category management, pagination, sorting, and validation using DTOs and custom exception handling.

> **Branch:** `PaginationandSorting`

---

## 📂 Project Structure


---

## ✅ Features Implemented

- 🔄 **Pagination & Sorting** for categories
- 📦 **DTO Pattern** for data abstraction
- ⚠️ **Custom Exception Handling** using `@ControllerAdvice`
- ✅ **Validation** using Hibernate Validator annotations
- 🧪 Well-tested endpoints with meaningful error messages
- 📁 Layered architecture (Controller, Service, Repository)

---

## 🧑‍💻 Technologies Used

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate Validator
- ModelMapper
- PostgreSQL (or H2 for testing)
- Maven
